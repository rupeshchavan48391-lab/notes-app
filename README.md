# 📌 Project Overview

This project is a **Django-based Notes Application** that has been transformed from a traditional web application into a **containerized and cloud-deployment-ready DevOps project**.

The project demonstrates the evolution of an application through multiple stages:

```text
Application Development
        ↓
Docker Containerization
        ↓
Docker Compose
        ↓
Gunicorn
        ↓
Nginx Reverse Proxy
        ↓
Docker Hub
        ↓
AWS EC2 Deployment
        ↓
Kubernetes Configuration
        ↓
Jenkins CI/CD

🚀 Project Highlights
🐍 Django web application
🐳 Docker containerization
🔗 Docker Compose multi-container deployment
⚙️ Gunicorn production WSGI server
🌐 Nginx reverse proxy
☁️ AWS EC2 cloud deployment
📦 Docker Hub container registry
🔧 Git & GitHub version control
☸️ Kubernetes deployment manifests
📁 Kubernetes Namespace, Deployment, Service & Ingress
🔄 Kubernetes scaling and rolling-update architecture
🤖 Jenkins CI/CD pipeline architecture
🔐 Production-oriented deployment structure
